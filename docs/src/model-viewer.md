# 只读 3D 模型查看器

点击项目中的 `.stl`、`.obj`、`.ply`、`.step` 或 `.stp` 文件打开模型标签页。模型查看器不保存或修改源文件。

- STL 支持二进制和 ASCII；OBJ 支持三角面与负索引；PLY 首版支持 ASCII 三角网格。非三角面、二进制 PLY、点云、材质和纹理暂不支持，会明确报错，不静默改变模型。
- 拖动旋转，Shift+拖动平移，滚轮缩放。工具栏提供等轴测与六面预设视角、重置视角、透视/正交投影切换、实体/实体+边线/线框三种着色模式，以及参考网格、坐标轴和属性面板开关。视口右上角是随视角一起转动的方向立方体：六个面分别标注 前/后/左/右/上/下，出画或过于侧向的面会隐藏标注，点击可见面切换到该视角，立方体下方的等轴测按钮回到默认视角。地面参考网格按屏幕尺度取格（一格约 56px，缩放时按 1/2/5×10ⁿ 换档），向模型四周铺到视口之外再按距离淡出，因此没有可见边界；每五格一条更亮的主线。左下角是坐标轴指示器（X 红、Y 绿、Z 蓝），底部状态栏显示交互提示与当前投影方式。
- 工具栏的剖面按钮启用剖切：模型按剖切平面被裁掉一半，切口轮廓用高亮线描出，默认并把切口封成实心截面。剖面卡片可选择 X/Y/Z 轴、拖动位置、翻转保留侧、开关封盖，并显示截面面积。剖切平面固定在模型坐标中，旋转相机不改变它。
- 右侧属性面板分组显示几何（三角面、唯一顶点、尺寸、单位，闭合网格还显示有向体积绝对值）、拓扑检查、截面和文件信息（格式、大小、表面积）。STL/OBJ/PLY 的单位是模型坐标单位，不推断毫米；STEP 按文件声明的长度单位换算为毫米并显示该单位。
- 拓扑检查提供精确坐标合并后的顶点数、边界边、非流形边、方向不一致的边、退化面，并以状态点标出是否存在问题。不超过 30 万面的模型在打开时自动检查，超大模型可在面板中手动触发。它不是容差焊接、完整流形证明或自交检测。
- 没有边界边、非流形边、方向错误与退化面时显示有向体积绝对值；未验证自交和嵌套壳体，不将它视为制造级体积认证。
- 已打开的模型标签页会跟随磁盘上的文件：文件被重新导出（例如脚本反复生成同名 STL）后自动重新读取并重解析，相机、预设视角、剖切平面与面板状态保持不变，因此可以直接把编辑器一侧的代码改动同步显示在模型视口里。写入尚未完成或解析失败时保留上一次成功显示的模型，文件被删除时也保留最后一次内容，重新生成后再自动刷新。

## STEP 零件与装配

STEP（ISO 10303-21，AP203/AP214/AP242）保存的是带曲面的 B-rep，不是三角网格，因此打开时由内置的纯 Rust 几何内核（`truck`）完成曲面细分，再把三角形交给同一个视口渲染。解析全部在客户端进行，服务端只按扩展名与大小返回文件字节。

- 读取 `MANIFOLD_SOLID_BREP`、`BREP_WITH_VOIDS`、`SHELL_BASED_SURFACE_MODEL` 引用的封闭/开放壳体；平面、圆柱、圆锥、球、圆环、B 样条/Bezier/有理曲面以及旋转、拉伸曲面都在支持范围内。
- 曲面边界的环绕方向按参数空间里真实投影出的边界折线判定，并对周期曲面按接缝折回；有理样条只在其有限参数区间内取样。判错环绕方向会让 `truck` 为单个面拼出整块参数矩形（看起来像横穿零件的碎三角面），把参数域外的点当成有效值则会让整个面消失。
- **装配**：按 `NEXT_ASSEMBLY_USAGE_OCCURRENCE` 与 `REPRESENTATION_RELATIONSHIP_WITH_TRANSFORMATION` / `ITEM_DEFINED_TRANSFORMATION` 递归展开，同一子零件被多次引用时按实例分别放置；`MAPPED_ITEM` + `CARTESIAN_TRANSFORMATION_OPERATOR_3D` 也会应用。
- **单位**：识别 `SI_UNIT`（mm/cm/µm/m）与 `CONVERSION_BASED_UNIT`（英寸/英尺及带换算因子的单位），所有坐标统一换算为毫米，属性面板的「单位」显示实际单位并新增「实体」数量。无法识别的单位按文件原始坐标显示。
- 装配中的颜色、图层、PMI 标注、2D 工程图、材质与纹理不显示；文件里的面颜色不会被猜测。
- 部分曲面类型（例如偏置曲面、`FACETED_BREP` 的多边形面）暂不支持：该壳体被跳过并写入日志，其余可解析的壳体照常显示；一个可显示实体都没有时标签页给出明确错误，不静默显示空视口。
- **无法细分几何的处理**：`truck` 通过递归二分曲线和切分曲面来逼近公差，退化几何（零长度参考方向、非有限坐标、远超模型范围的控制点）永远达不到公差，一次细分就能生成指数级的工作量并耗尽进程内存。加载前先按同一判据做有界检查，不合格的面连同只被它引用的边和顶点一起丢弃并写日志，其余面、壳体和装配照常显示；整个文件都没有可细分几何时才报错。这样解析器的内存和耗时由预算而不是文件内容决定。
- 曲面细分使用相对包围盒对角线的公差（约 0.05%），超过 200 万三角形时自动把公差放大 4 倍重试，最多两次；仍超限则报错。细分后的网格是三角化近似，**不做**精确拓扑检查，属性面板会显示说明而不是把细分接缝当成模型缺陷。

## 剖面边界

- 剖切按三角面在模型空间对半空间裁剪，切口轮廓直接来自裁剪交点。封盖把交点线段按坐标合并成闭合环，用偶奇规则填充，因此非凸截面、多个分离截面和孔洞都成立，且不要求网格绕向一致。截面面积按同一偶奇规则在平面内积分，单位为模型坐标单位的平方。
- 封盖只在不超过 30 万面的模型上构建（与拓扑检查同一门槛），超限时仅裁剪并描轮廓，面板给出提示；面积显示为未指定。
- 开放或非流形曲面无法围出封闭环，此时只描轮廓，不生成封盖，截面面积不可信。

## 资源预算

文件上限 128 MiB（STEP 为 256 MiB），模型上限 200 万三角面，拓扑检查上限 30 万面；STEP 另有限制 50 万个面、4096 个壳体（含装配展开后的实例）、每条边 4096 次细分步、每个 B 样条/有理曲面 65536 个参数栅格、120 秒解析预算。CPU 几何使用 f64，约 72 字节/面（100 万面约 68.7 MiB），加载时还会存在文件字节和解析临时数组。OBJ/PLY 顶点数组与向量容量会增加峰值。

渲染按需执行，单视图分辨率不超过 1280×960，颜色缓冲约 4.7 MiB、深度缓冲约 9.4 MiB。使用 CPU 深度缓冲，不持续动画；大模型旋转性能需要实机验证。多个分屏共享解析后的几何；检查边表计算后释放，只保留统计计数。关闭最后一个视图释放几何和后台任务，移除渲染图集条目。分配器与 GPU 驱动可能保留可复用内存，因此进程 RSS 不保证立即下降到完全相同的数值。

剖切本身不复制网格，每个三角面只在本帧的栈上临时生成被裁剪的多边形，额外内存为常数。封盖需要把切口线段按坐标合并成环，构建期间峰值约为每条交线几十字节，30 万面模型最坏约几十 MiB，构建完成后释放临时表，只保留闭合环与面积；封盖结果只与平面有关，旋转相机时复用，不重复构建。

## 远程边界

远程复用只读 1 MiB 文档分块协议，额外要求 `model_chunks_v1` 能力和既有 Zed CN 来源门控。STEP 沿用同一通道：服务端只需把 `step`/`stp` 纳入文档扩展名白名单并按 256 MiB 校验大小与修改时间，解析与细分全部在客户端，因此 Windows 客户端连接 Linux 服务端不存在路径或程序启动差异。旧版或官方服务器不接收模型请求，无本地路径回退。远程服务端只读取，客户端解析与渲染。WSL/Docker/协作仍受既有来源门控限制，不宣称首版支持。

使用 SSH 远程模型预览时，在该连接的「服务端选项」中选择 Zed CN 来源，并使用包含模型查看器功能的客户端和服务端后重新连接。仅支持 PDF/Excel 等文档读取的旧服务端不够；缺少模型读取能力时，标签页会明确提示需要支持模型读取的 Zed CN SSH 服务端。模型文件无需预先下载到客户端目录。

## 人工验证

1. 本地打开二进制/ASCII STL、三角面 OBJ 与 ASCII PLY，检查视角、缩放、平移、窗口调整。
2. 拆分模型标签；关闭其中一个仍能查看，关闭最后一个后观察内存及后台任务退出。
3. 核对打开前后原文件 SHA-256 一致；尝试无效索引、截断 STL、非有限坐标和超限文件。
3.1 打开毫米与英寸单位的 STEP 各一个，核对属性面板的单位与尺寸；打开含两个零件的装配，确认第二个零件按变换矩阵偏移而不是叠在原点。
4. Windows 客户端连接新版 Linux Zed CN 服务端打开模型；官方/旧版服务端必须明确拒绝，不能读取本机同名路径。
5. 性能与 RSS 在原生 Windows/macOS/Linux、真实 SSH 上分别测量；自动化单元测试不代替这些实机验证。
6. 在闭壳零件上开启剖面：核对 X/Y/Z 三轴、位置拖动、翻转方向、封盖开关与截面面积；把剖切位置移到模型外应恢复完整模型；在空心件上检查孔洞是否被正确扣除。
7. 大模型（30 万面以上）开启剖面应显示封盖不可用提示并仍能裁剪、描轮廓；实测 200 万面模型拖动剖切位置的延迟与 RSS。

尚无测距、问题位置高亮、任意法向剖切平面、二进制 PLY及多边形三角化；STEP 无颜色、图层、PMI 与 2D 图纸，偏置曲面与 `FACETED_BREP` 不显示。
