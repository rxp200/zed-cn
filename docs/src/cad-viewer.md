# 只读 2D CAD 图纸查看器（DXF）

点击项目中的 `.dxf` 文件打开图纸标签页。查看器不保存或修改源文件，也不会把图纸转换为其他格式。

## 支持范围

- 支持 **ASCII DXF**，覆盖 R12 至 R2018 的组码/值文本格式，含 HEADER、TABLES/LAYER、BLOCKS 与 ENTITIES 段。
- **不支持的格式会明确说明原因，不会静默显示空白**：`.dwg`/`.dwt`/`.dws`（DWG 容器，提示导出为 DXF）、二进制 DXF（`.dxb` 或带 `AutoCAD Binary DXF` 哨兵的文件，提示另存为 ASCII）、以及不是 DXF 的文件。
- `.dxf` 扩展名由查看器接管。需要直接编辑文本时，使用工具栏的「以文本方式打开」（`Ctrl/Cmd+Shift+E`）在编辑器中打开同一个文件。

## 绘制内容

- 几何：`LINE`、`CIRCLE`、`ARC`、`ELLIPSE`、`LWPOLYLINE`（含 bulge 圆弧）、`POLYLINE`/`VERTEX`/`SEQEND`、`SPLINE`、`POINT`、`SOLID`/`TRACE`、`3DFACE`、`LEADER`、`INSERT`（块引用，含嵌套）与 `DIMENSION`（按其匿名块展开）。`XLINE`/`RAY` 按图纸范围裁剪后绘制。
- 文字：`TEXT` 与 `MTEXT`，剥离 DXF 格式码（`\P`、`\f...;`、`%%d` 等）后按真实字体绘制。文字实体在标签层上绘制，只有投影高度不小于 7 像素且在视口内的标签才会显示，单帧上限 800 条。
- 颜色：按图层色与实体色解析。支持 24 位真彩色（组码 420）与标准 AutoCAD 颜色索引（ACI）调色板；ACI 7 按当前主题前景色渲染，因此深色与浅色主题下的图纸都可读。
- 文字编码：R2007（`AC1021`）及以后按 UTF-8 解码；更早的版本按 `$DWGCODEPAGE` 声明解码（含 `ANSI_936`/GBK 中文图纸），未声明时回退到 Windows-1252。

## 已知限制

- 不生成图案填充：`HATCH`、`MLINE`、`IMAGE`/`WIPEOUT`/`*UNDERLAY` 外部引用与 ACIS 实体（`3DSOLID`/`REGION`/`BODY`/`SURFACE`）不绘制，只在状态栏按实体类型统计数量。外部引用路径永远不会被读取。
- `SPLINE` 用拟合点（没有拟合点时用控制点）近似为折线，不做精确 NURBS 求值。
- 圆弧按固定 5° 角步离散，因此极高倍数放大时可见折线。
- 忽略线型（虚线按实线绘制）、线宽与`图纸空间`内容；图纸空间实体被跳过并在状态栏计数。
- 图层「0」上的块内实体按 DXF 规则继承插入实体的图层；块内按块颜色（ByBlock）继承未实现。

## 交互

- 拖动平移，滚轮以光标为中心缩放，工具栏提供适配范围、放大、缩小、实际大小（1 图纸单位 = 1 像素）以及栅格开关。
- 右侧图层面板逐层显示颜色与显隐开关，可单独关闭图层；「适配范围」只考虑当前可见图层。
- 底部状态栏显示图纸范围尺寸、已绘制图元数、单位（`$INSUNITS`）、被跳过的图纸空间实体数与不支持实体数、截断提示与当前缩放比例。

## 资源预算

- 文件上限 64 MiB；点预算 200 万、折线 100 万、填充 20 万、文字 5 万、图层 4000、块展开深度 4。达到预算时图纸被截断并在状态栏提示，不会继续增长。
- 解析采用流式方式并直接展平为紧凑场景，**不保留原始文件字节**：打开完成后 `DocumentItem` 释放字节，只保留渲染场景（约 16 字节/点 + 12 字节/折线）。
- 光栅化在后台线程执行，单帧像素不超过约 123 万（1280×960），并保持视口宽高比；单帧绘制线段上限 40 万，超出时状态栏提示「部分未绘制」。关闭标签页会取消后台渲染并释放帧图集条目。

## 远程边界

远程复用只读 1 MiB 文档分块协议（Proto 510/511），只要求 `cad_documents_v1` 能力；所有远程连接现在都使用 Zed CN Remote Server。旧版服务端不接收图纸请求，**没有本地路径回退**。服务端只按 `project::document_file_size_limit` 校验扩展名、大小与修改时间并读取字节，解析与渲染全部在客户端完成，因此 Windows 客户端连接 Linux 服务端不涉及路径或程序启动的跨主机差异。

使用 SSH 远程预览时，使用匹配当前客户端版本的 Zed CN Remote Server 重新连接。缺少 `cad_documents_v1` 时，打开标签页之前就会提示需要支持 CAD 图纸预览的 Zed CN 服务端。

## 人工验证

1. 本地打开 ASCII DXF（含中文 `$DWGCODEPAGE`/`ANSI_936` 图纸），检查平移、缩放、适配范围、栅格与图层显隐。
2. 打开 DWG、二进制 DXF、重命名为 `.dxf` 的 DWG 与损坏/截断文件，确认提示文案正确且不静默空白。
3. 打开含块引用、圆弧、文字标注与图纸空间实体的图纸，核对状态栏统计与「已知限制」一致。
4. 拆分图纸标签；关闭其中一个仍能查看，关闭最后一个后确认字节与帧图集被释放。
5. 用「以文本方式打开」打开同一个 `.dxf`，确认编辑器标签与图纸标签可并存，且源文件 SHA-256 不变。
6. Windows 客户端连接新版 Linux Zed CN 服务端打开 `.dxf`；官方/旧版服务端必须在打开标签页之前明确拒绝，且不得读取客户端本机同名路径。
7. 性能与 RSS 在原生 Windows/macOS/Linux、真实 SSH 上分别测量；自动化单元测试不代替这些实机验证。
