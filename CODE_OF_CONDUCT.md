# Code of Conduct

> [!IMPORTANT]
> Zed CN is an unofficial community fork and is not operated, sponsored, or endorsed by Zed Industries. Until this repository adopts its own code of conduct, contributors are asked to follow the official Zed project's [Code of Conduct](https://zed.dev/code-of-conduct) as community guidance. Enforcement and moderation for Zed CN are handled by this repository's maintainers, not by Zed Industries.
