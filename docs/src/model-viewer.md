# 只读 3D 模型查看器

点击项目中的 `.stl`、`.obj` 或 `.ply` 文件打开模型标签页。模型查看器不保存或修改源文件。

- STL 支持二进制和 ASCII；OBJ 支持三角面与负索引；PLY 首版支持 ASCII 三角网格。非三角面、二进制 PLY、点云、材质和纹理暂不支持，会明确报错，不静默改变模型。
- 拖动旋转，Shift+拖动平移，滚轮缩放。工具栏提供等轴测与六面预设视角、重置视角、透视/正交投影切换、实体/实体+边线/线框三种着色模式，以及参考网格、坐标轴和属性面板开关。视口带有地面参考网格和左下角坐标轴指示器（X 红、Y 绿、Z 蓝），底部状态栏显示交互提示与当前投影方式。
- 右侧属性面板分组显示几何（三角面、唯一顶点、尺寸、单位，闭合网格还显示有向体积绝对值）、拓扑检查和文件信息（格式、大小、表面积）。单位为模型坐标单位，不推断毫米。
- 拓扑检查提供精确坐标合并后的顶点数、边界边、非流形边、方向不一致的边、退化面，并以状态点标出是否存在问题。不超过 30 万面的模型在打开时自动检查，超大模型可在面板中手动触发。它不是容差焊接、完整流形证明或自交检测。
- 没有边界边、非流形边、方向错误与退化面时显示有向体积绝对值；未验证自交和嵌套壳体，不将它视为制造级体积认证。

## 资源预算

文件上限 128 MiB，模型上限 200 万三角面，拓扑检查上限 30 万面。CPU 几何使用 f64，约 72 字节/面（100 万面约 68.7 MiB），加载时还会存在文件字节和解析临时数组。OBJ/PLY 顶点数组与向量容量会增加峰值。

渲染按需执行，单视图分辨率不超过 1280×960，颜色缓冲约 4.7 MiB、深度缓冲约 9.4 MiB。使用 CPU 深度缓冲，不持续动画；大模型旋转性能需要实机验证。多个分屏共享解析后的几何；检查边表计算后释放，只保留统计计数。关闭最后一个视图释放几何和后台任务，移除渲染图集条目。分配器与 GPU 驱动可能保留可复用内存，因此进程 RSS 不保证立即下降到完全相同的数值。

## 远程边界

远程复用只读 1 MiB 文档分块协议，额外要求 `model_chunks_v1` 能力和既有 Zed CN 来源门控。旧版或官方服务器不接收模型请求，无本地路径回退。远程服务端只读取，客户端解析与渲染。WSL/Docker/协作仍受既有来源门控限制，不宣称首版支持。

使用 SSH 远程模型预览时，在该连接的「服务端选项」中选择 Zed CN 来源，并使用包含模型查看器功能的客户端和服务端后重新连接。仅支持 PDF/Excel 等文档读取的旧服务端不够；缺少模型读取能力时，标签页会明确提示需要支持模型读取的 Zed CN SSH 服务端。模型文件无需预先下载到客户端目录。

## 人工验证

1. 本地打开二进制/ASCII STL、三角面 OBJ 与 ASCII PLY，检查视角、缩放、平移、窗口调整。
2. 拆分模型标签；关闭其中一个仍能查看，关闭最后一个后观察内存及后台任务退出。
3. 核对打开前后原文件 SHA-256 一致；尝试无效索引、截断 STL、非有限坐标和超限文件。
4. Windows 客户端连接新版 Linux Zed CN 服务端打开模型；官方/旧版服务端必须明确拒绝，不能读取本机同名路径。
5. 性能与 RSS 在原生 Windows/macOS/Linux、真实 SSH 上分别测量；自动化单元测试不代替这些实机验证。

尚无截面、测距、问题位置高亮、二进制 PLY及多边形三角化。
