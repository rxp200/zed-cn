# 只读 Word 文档查看器

点击项目中的 `.docx`、`.docm`、`.dotx` 或 `.dotm` 文件打开 Word 文档标签页。查看器只读，不保存、不修改源文件，也不执行文档中的宏（`vbaProject.bin` 等宏部件被直接忽略）。

## 支持的内容

- 标题（按样式的 outline level 还原为 H1–H6）、段落、加粗、斜体、下划线、删除线，等宽字体段落显示为代码样式。
- 项目符号与编号列表，按 `numbering.xml` 还原多级嵌套；列表层级来自段落自身的编号属性。
- 表格（含跨列 `gridSpan`）、单元格内换行、文档内嵌图片、超链接。
- 超链接只把 `http`/`https` 交给系统浏览器打开，其余链接不会触发任何外部访问。
- 中文与英文文本按 UTF-8 解码；文档中的制表符与手动换行按普通文本保留。

## 不还原的内容

这是阅读视图而不是排版引擎。分页、页眉页脚、脚注尾注、文本框与浮动位置、分栏、精确行距与缩进、文档内嵌字体、SmartArt、图表、公式（OMML）、批注、修订标记（删除的文字不显示）、内嵌 OLE 对象、外部关系（`altChunk`、链接图片、外部模板）都不还原，也不做任何外部抓取。域代码（如 `PAGE`、`TOC` 的控制串）只显示文档上次保存时缓存的文本，不重新计算。

旧版二进制 `.doc`、`.rtf`、`.odt`、`.pptx`、`.pages`/`.numbers`/`.key`、`.wps`/`.et`/`.dps`、`.vsdx`、`.one` 等格式不被本查看器接管，仍按原来的方式打开；需要阅读时请先用办公软件另存为 `.docx`。

## 资源预算

Word 文件是 ZIP 容器，查看器按条目分块读取，容器本身不会整体进入内存，因此内存占用不随文件大小线性增长。

- 文件上限 256 MiB；单个条目上限 64 MiB；每次分块请求 1 MiB。
- 正文部件上限 32 MiB，样式 / 编号 / 关系等辅助部件各 16 MiB；生成的 HTML 上限 24 MiB、最多 5 万个块。
- 图片最多 128 张、单张压缩上限 16 MiB、压缩总量上限 32 MiB、解码后总量上限 64 MiB。到达预算时后续图片不再加载，标签页顶部提示预览已截断。
- 正文或块数超限时同样截断并提示，不静默丢弃已渲染内容。关闭标签页会取消加载任务并释放已加载图片。

## 远程边界

远程 SSH 工作区复用只读的文档条目不传输整包协议，只要求服务端广播 `office_entries_v1` 能力；所有远程连接现在都使用 Zed CN Remote Server。不广播该能力的旧版服务端不会收到任何 Word 请求，标签页会明确提示需要支持文档读取的 Zed CN 服务端，不回退为本地读取，也不整包下载。服务端只按扩展名、大小和修改时间校验并读取条目字节，解析与渲染全部在客户端完成，因此 Windows 客户端连接 Linux 服务端时不存在路径或进程启动的跨主机差异。WSL/Docker 同样使用 Zed CN Remote Server，协作会话仍不支持该协议。

## 人工验证

1. 本地打开含标题、多级列表、表格、图片、超链接和中文的 `.docx`，核对结构与主题配色；切换浅色/深色主题。
2. 打开含大量图片或超长正文的文档，核对截断提示与内存表现；关闭标签后确认加载任务结束。
3. 核对打开前后原文件 SHA-256 一致；尝试损坏 ZIP、非 ZIP 改名的 `.docx`、超大文件与 `.doc` 等不受支持格式。
4. Windows 客户端连接新版 Linux Zed CN 服务端打开仅存在于远端的 `.docx`；官方/旧版服务端必须给出明确提示，不能读取本机同名路径。
5. 图片渲染、字体缩放快捷键、重启恢复标签页与 RSS 曲线需在原生 Windows/macOS/Linux 与真实 SSH 上实测；自动化单元测试不代替这些实机验证。

尚无编辑、目录侧栏、查找、导出和打印。
