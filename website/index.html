05 / BEFORE YOU GO

说清楚，
再出发。

关于版本、来源与边界。

这是 Zed 的官方网站吗？＋

不是。Zed CN 是基于 Zed 的社区中文定制版，与 Zed Industries 没有官方隶属或背书关系。Zed 官方网站是 zed.dev。此站展示本项目代码中的能力，不代表官方产品承诺。

Stable 与 Dev 应该怎么选？＋

日常使用优先 Stable。Dev 是开发发布流，在 GitHub 标记为预发布，适合愿意验证新改动的用户。两者共享安装与应用数据位置，不应当作彼此隔离的环境；切换前建议备份设置。版本是否有可下载资产，以清单为准。

为什么某个平台的版本不是最新的？＋

不同平台的构建结果可能不同。这里为每种资产选择清单中最新的可用版本，并逐项展示其真实版本，不把较旧安装包标成最新。缺少的架构不会生成下载链接。

AI 是否开箱即用？会把代码发送到哪里？＋

需要按功能配置模型与凭据。使用远程模型时，相关输入会交由所选模型提供方处理；本地模型也需要相应服务与模型能力。本站没有后端，不收集凭据，也不提供或承诺免费的模型服务。

远程开发需要哪一种服务端？＋

SSH 支持官方与 Zed CN 来源。新增能力可能依赖匹配的定制服务端及能力协商；仅有相同应用版本并不等于兼容。切换来源不会自动重启正在运行的工作空间，请阅读当前发布说明。

许可证与商标如何处理？＋

Zed 与 Zed CN 的代码以仓库对应的 GPL、Apache-2.0 等许可证文件为准。Zed 名称及相关标识属于其权利人。网站的 Three.js 使用 MIT 许可证，详情见网站第三方声明。
